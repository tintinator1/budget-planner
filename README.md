## MVP scope (current)

Budget Planner helps you build a budget for any goal with the assistance of AI for personalized understanding

User flow:

1. Enter monthly income
2. Enter monthly expenses
3. Set a savings goal, target amount, and timeframe
4. Generate a plan — see calculated numbers, or try BudgetAI for a deeper understanding

## Stack

- **Next.js 16** (App Router, TypeScript)
- **Tailwind CSS 4**
- **OpenAI (gpt-4o-mini) for structured advice**
- **Vitest** unit testing
- **Next.js API routes**
