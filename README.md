## MVP scope (current)

Frontend only. No database, no auth, no AI API yet.

User flow:

1. Enter monthly income
2. Break down monthly expenses
3. Set a savings goal, target amount, and timeframe
4. Submit → validated `BudgetPlanInput` (calculator wiring comes next)

## Stack

- **Next.js 16** (App Router, TypeScript)
- **Tailwind CSS 4**

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
